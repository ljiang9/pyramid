# pyramid — 金字塔纸牌

终端里的金字塔纸牌 (Pyramid Solitaire)。28 张牌摆成 7 层金字塔,
把点数加起来等于 13 的牌对移走(A=1, J=11, Q=12, K=13 单独移走)。
只有"完全暴露"(下方两张牌都已移走)的牌和废牌堆顶可以移。
清掉整个金字塔即获胜。

纯标准库,零依赖。

## 玩法

```bash
python -m pyramid                 # 开始一局
python -m pyramid --seed 42       # 固定牌序
python -m pyramid --auto          # 贪心机器人自动玩一局
```

交互命令:

| 命令      | 说明                          |
|-----------|-------------------------------|
| `1 3`     | 移走编号 1 和 3 的牌(和须为 13) |
| `2`       | 单独移走编号 2 的牌(必须是 K)   |
| `w 1`     | 废牌堆顶和编号 1 配对          |
| `d`       | 从牌堆翻一张到废牌堆          |
| `h`       | 帮助                          |
| `q`       | 退出                          |

## 设计取舍

- 牌堆翻牌次数不限(经典规则有的版本限 1-3 次,这里为了"小巧"不限)。
- 废牌堆顶可参与配对,这是标准规则。
- 贪心机器人优先移金字塔牌、能移 K 先移 K。

## 已知局限

- 无悔棋、无存档、无最佳成绩。
- 机器人是贪心策略,实测 500 局胜率约 0.4%(这是纸牌本身的难度,非代码问题)。
- 行输入模式,每步需回车;不支持鼠标。
